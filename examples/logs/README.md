# Golden logs

`sim.csv` is a 4 s closed-loop MPC point-to-point on `examples/vehicles/fan_plus.json` (seed 7). `hardware.csv` is the **same trajectory family** with a 1-step command delay and Gaussian pose noise — an **example hardware-shaped log (synthetic mocap noise)**, schema-valid (`# airbearing_log schema_version=1 units=SI`), not a recording from a physical table. Regenerated by `python scripts/make_golden_logs.py`. Compare offline:

```bash
airbearing compare --sim examples/logs/sim.csv --real examples/logs/hardware.csv
```
